# galgame 模式 · 说明书

一句话：**发 `gal 开局`，机器人给你演一场戏；你随便说你想做什么，故事就跟着你的动作往下走。**

它跟平时聊天不是同一套东西：进了这个模式，这条会话由剧本接管，不再走普通生图/聊天链。

---

## 一、一分钟上手

```
你：gal 开局

它：放学后的走廊里浮着薄薄一层樱色，半开的窗外飘进几片花瓣。
    她抱着一摞素描本迎面走来，看见你时脚步慢了半拍。「……早。」
    话刚出口，最上面那本没抱稳，哗啦一下滑落，纸页散了一地。

    A. 蹲下去帮她捡纸
    B. 先问她没事吧
    C. 把飘落的花瓣拾起来
    （选项只是偷懒用的，直接说你想做什么也行）

你：你怎么了，脸色不太好

它：她睫毛颤了一下，视线落到自己脚尖。
    「……没什么。只是熬夜画分镜，没睡好。」
    抱书的手臂却又收紧了几分，像怕被看出什么。
    ← 这一轮聊了，但"必须发生的事"没做，所以还在第一章

你：我蹲下去，把散落的纸一张张收好，递到她手里

它：你蹲下身，把散落的画纸一张张收拢，递了过去。
    她接过来时指尖有些发凉。「……谢谢。」
    顿了顿，声音更轻了，「那个，我——下个月，可能就要搬走了。」

    ——— 第 2 章 · 天台上的两个人 ———
    ← 这一轮真做到了，翻章
```

要点只有三条：

1. **你说什么都会算数**，不用非得回字母。回 `A` / `B` / `C` 只是"替我把那条建议打出来"。
2. **翻章看你有没有真的做到**，不是看聊了多久。每一章有一件「必须发生的事」，做到了才往下走。
3. **她记得你做过什么**。做过的事会进"记得的事"清单，影响她后面怎么对你。

## 二、命令表

| 命令 | 作用 |
|---|---|
| `gal 开局` | 用默认剧本开始 |
| `gal 开局 sakura` | 指定剧本（写 id 或中文标题都认） |
| `gal 剧本` | 看有哪些剧本 |
| `gal 状态` | 当前第几章、好感多少、记得几件事 |
| `gal 存档` / `gal 存档 名字` | 存一个档 |
| `gal 读档 名字` | 回到那个档 |
| `gal 结束` | 退出模式，恢复普通聊天 |
| `gal` | 不带参数 = 打印命令表 |

同义词：`开始`/`模式`/`start`/`新游戏` = `开局`；`退出`/`end`/`stop` = `结束`。

**群里不用抠格式**：`@大大怪 gal 开局`、`大大怪 gal 开局`、`大大怪，gal 开局`、
`gal模式`、`gal开局` 全都认——命令词前面喊了名字（或真 @ 过）就自动忽略，
`gal` 后面不带空格也能接中文子命令。但 `galgame`、`galaxy`、`gallery` 这类
英文词不会被当成命令。

> ⚠️ **`gal 开局` 会覆盖当前进度。** 玩到一半想重来，先 `gal 存档 重来前`。

## 三、到底怎么才能往下走

这是唯一需要理解的一件事。

每一章有两条信息：

- **必须发生的事**：这一章的目标，做到了才翻章
- **她心里悬着的事**：还没说出口的那件，会一直提示模型往这上面收

模型每一轮都会做一件事：**判断你刚才做的事，算不算把目标做到了。**

```
目标：你帮她把散落的纸捡起来，还到她手里

你问「你怎么了」            → 不算（只是在问）
你聊「今天天气真好」         → 不算（没推进）
你说「我蹲下去一张张收好，递给她」 → 算，翻章
```

判定松紧有两道保险：

- **最少轮数**：每章至少演 2 轮才能翻，防止一句话通关
- **最多轮数**：到上限强制翻章，防止模型一直不肯放行、你在原地转到烦

两个数都写在剧本里（`min_turns` / `max_turns`），想改随时改。

## 四、好感与「记得的事」

`gal 状态` 会显示两样东西：

```
《樱花庄的午后》
第 2 / 4 章 · 天台上的两个人
好感：3
记得的事：4 条
```

**好感**（-50 ~ 50）只影响台词语气：高了她会主动一点，低了她会躲。单轮最多变 5，所以刷不起来。

**记得的事**是硬约束，但只收**能核对真假的客观事实**——她收下了伞、你知道她要搬走、素描本在你手上。像「她有点害羞」「氛围变温柔」这种一律不收，那些演完就过去了。最多保留 8 条，满了挤掉最旧的。

**她还记得刚才的对话**。每轮都会带上最近 6 句（你说的 + 她回的），所以接着上一句问「然后呢」「你手怎么这么凉」都接得住，她不会装作没听见。超过 6 句的自动忘掉——这是故意的，一章的戏不需要从头背到尾。

底线在这儿：**世界会回应你，但不会迁就你。** 你说"我给你一千万"，她会回你一句，但不会真的变出一千万——那不是剧本里的东西。

## 五、私聊和群聊

| | 私聊 | 群聊 |
|---|---|---|
| 进度归谁 | 你自己一条线 | **整个群共享一条线** |
| 别人插进来 | 不存在 | 会影响同一份进度 |
| 机器人知道是谁说的吗 | 不需要 | 知道，会带上发言人的名字 |
| CG 发到哪 | 发给你一个人 | 发到群里 |

群聊共享进度是**故意**的：十个人十条线的话，机器人回谁的话都对不上。想沉浸就私聊，群聊当跑团玩。

一个人私聊一条线、在群里又是另一条线，互不影响。

> 群里人多的时候，一句一句自由输入容易乱。想稳一点就回字母，大家都回 `A` 就是推进同一个方向。

## 六、结局

最后一章（现在是第 4 章「站台」）达成目标后，模型会从剧本里挑一个结局，代码只校验 id 合不合法：

```
你：你留下吧，我等你回来
它：她抓着行李箱的手松开了……
    【樱花色的下午】
    （想再玩一次就发 gal 开局）
```

- 结局由**整局做过的事**决定，不是某一句话决定的
- 想换一个结局，得从关键章节重来（`gal 存读` 或者直接 `gal 开局`）
- 结局一到，模式自动退出，回到普通聊天

## 七、存档

```
gal 存档            → 默认档位 slot
gal 存档 樱花前      → 存成「樱花前」
gal 读档 樱花前      → 回到存档时的章节开头
```

- 进度：`state/galgame_sessions.json`
- 存档：`state/galgame_saves/<会话>/<名字>.json`
- 存档记的是"第几章 + 第几轮 + 好感 + 记得的事"，读回来停在那一章开头
- 旧版（按节点存的）存档已经用不了了，`gal 读档` 会直接告诉你

> ⚠️ **`gal 结束` 和走到结局都会清空这个会话的所有存档**（`leave()` 里的 `_drop_slot()`）。所以存档实际是**局内回退点**，不是跨局存档。想在结局后回头看看另一条路，得重新开局。
>
> 这条是原样保留的旧行为，要改成"只在新开一局时清"随时可以，说一声。

## 八、CG

- 只有在剧本里标了 `cg` 的章节才出图，现在一个剧本 4 张
- **同一章只出一次**，重走不重画
- 翻章那一轮不出图（那一轮正文还是上一章的收尾，图和文对不上），等下一轮进了新章再出
- 正文先发，图后台慢慢出，几十秒后跟上，**不用等图**
- 渠道是 `anima-line`，2456×3686 竖屏
- 长相由 `cast` 指定的角色卡钉死（现在是 `izumi_sagiri` 和泉纱雾）

## 九、自己写一个剧本

把一个 `.json` 丢进 `galgame/` 目录，`gal 剧本` 下次就会列出来，**不用重启**。

```json
{
  "id": "my_story",
  "title": "我的故事",
  "cast": "izumi_sagiri",
  "beats": [
    {
      "id": "ch1",
      "name": "第一章的名字",
      "scene": "这一章开场是什么场面，写两三句，模型挂了就原样发这句",
      "goal": "这一章必须发生的一件事，写具体、可判断",
      "tension": "她心里悬着、还没说出口的那件事",
      "min_turns": 2,
      "max_turns": 5,
      "cg": "english scene description, only if you want an image"
    }
  ],
  "endings": [
    { "id": "good", "when": "什么样的情况算这个结局", "end": "结局名" }
  ]
}
```

| 字段 | 作用 |
|---|---|
| `id` | 剧本 id，也是文件名（`my_story.json` → `my_story`） |
| `title` | 显示名，`gal 开局` 后面可以直接写它 |
| `cast` | 角色卡 id，CG 用这张卡的固定外观 |
| `beats` | 章节数组，**按顺序推进**，最后一个之后进结局判定 |
| `endings` | 结局表，模型挑 id，代码校验 |

单章：

| 字段 | 作用 |
|---|---|
| `name` | 章名，翻章时发给玩家看 |
| `scene` | 开场场面，也是模型挂掉时的兜底文案 |
| `goal` | **必须发生的事**，模型靠它判断要不要翻章，所以要写得具体 |
| `tension` | 心里悬着的事，模型每轮都看，会自己把话题拉回来 |
| `min_turns` / `max_turns` | 这一章最少/最多演几轮 |
| `cg` | 画面描述，**写了才出图** |

写剧本的三条经验：

1. **`goal` 要写"能被做出来的动作"**，别写"她对你敞开心扉"这种没法判断的。好例子：`你帮她把散落的纸捡起来，还到她手里`。
2. **`tension` 别和 `goal` 重复**。goal 是"要做的事"，tension 是"她心里的事"，两件事分开，模型才不会把"她说出来了"当成"你做完了"。
3. **`endings` 第一条是兜底**。模型给出不存在的结局 id 时用它，所以放最中性的那个。

JSON 有语法错误时，只会让**这一个**剧本从列表里消失，其他剧本照常能用，机器人不会崩。

## 十、文件都在哪

| 路径 | 是什么 |
|---|---|
| `app/galgame.py` | 引擎：读剧本、判翻章、存进度、出 CG |
| `galgame/*.json` | 剧本 |
| `state/galgame_sessions.json` | 当前每个人的进度 |
| `state/galgame_saves/` | 存档 |
| `app/qq_bot.py` | 接入点：命令拦截、回合分流 |

改 `galgame/*.json` **立即生效**（每次现读盘）；改 `app/galgame.py` 要**重启 QQ 机器人**。

## 十一、常见问题

**Q：我回 `A` 了，为什么没翻章？**
A：`A` 只是替你把那条建议打出来，翻不翻章还是看"必须发生的事"做没做到。另外每章至少演 2 轮。

**Q：同一句话，别人玩和我玩结果会一样吗？**
A：不会。翻章判定和台词都是模型当场生成的，只有章节骨架和结局表是写死的。所以同一章走两遍，细节会不一样，但主线不会跑偏。

**Q：她为什么不按我想的做？**
A：她有自己的反应。你说"她扑进我怀里"，她可能只是脸红着退半步——这不是 bug。硬规则只有一条：**你不能替她决定她的动作**。

**Q：图一直没出来？**
A：图是后台出的，文字先到。一张几十秒，ComfyUI 在忙会更久，不影响继续玩。

**Q：`gal 结束` 之后进度还在吗？**
A：不在了。退出会同时清掉进度和这个会话的存档。

**Q：能同时开两个剧本吗？**
A：不能，一条会话同一时间只能在一个剧本里。要换就 `gal 结束` 再 `gal 开局 另一个`。

**Q：模型一直不肯翻章怎么办？**
A：到 `max_turns` 会强制翻，卡不死。只是会多演几轮。

# tools/legacy

一次性探针、验证、对比、临时脚本。它们记录了当时的排查过程，但不是运行时依赖。

规则：

- 不要从 `app/`、`tests/`、`web/` import 这里的文件。
- 这些脚本里的路径通常按“从仓库根目录运行”写成，移动后仍建议在仓库根目录执行。
- 如果某个脚本已经完全过期，先确认没有测试/文档引用，再删除；不要批量清空。
- 新的一次性脚本放这里，不要再堆回仓库根目录。
- 少数脚本里仍写死旧目录 `D:\AI\agent_my_test`（日志、临时输出、skills）。运行前先 `Select-String` 查一遍，确认它不会读写旧工作目录。

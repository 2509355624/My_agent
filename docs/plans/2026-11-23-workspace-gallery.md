# 方案卡：workspace 画廊模块（AI 创作）

日期：2026-11-23 · 分支 `my_agent_restructure` · 目录 `web/workspace/`

## 目标

聊天页 chip「AI 创作」现在只弹一个空壳。本期把它做成真画廊：顶部文件夹横滑标签 +
两列缩略图墙 + 点开单图查看器（收藏 / 下载）。**只写前端**，接口全部复用
`/api/gal/*`，不动任何 `.py`。

## 范围

做：

1. `css/gallery.css`：文件夹 chips 行、两列网格、卡片、骨架屏、空态、全屏查看器。
2. `js/gallery.js`：拉 `/api/gal/list`、按 `grp` 切分类、滚动到底加页、点开
   `/api/gal/work/<id>` 进查看器（左右滑 / 收藏 / 下载）。
3. `js/views.js` 加一个很小的注册口：允许某个子页自己接管顶栏中段和内容区，
   不给 `gallery` 以外的页面用上。

不做（下一批）：

- **做同款**：要把图反推成提示词，后端没有 HTTP 口（`_recall_tags` 只在
  `direct_gen` 内部）。这需要动 `.py` + 重启 5174，单独一批做，不在这里放个假按钮。
- 站长工具（扫描 / 隐藏 / 上传）、公开墙与「我的」来源切换：`我的` 页做的时候一起。
- 长按多选、批量下载。

## 模块边界

| 文件 | 职责 |
| --- | --- |
| `js/gallery.js` | 只认 `/api/gal/*`，通过 `WSApi` 发请求；渲染全在这里 |
| `js/views.js` | 子页壳 + 注册口；不认识图片接口 |
| `css/gallery.css` | 只用 `tokens.css` 的变量，不写死颜色 |

依赖方向仍是：`gallery.js` → `api.js`；`views.js` 不反向依赖 `gallery.js`。

## 交互

- 顶栏：左 ✕ 回聊天；中间文件夹 chips 横滑（默认「全部」）；右用户图标进「我的」。
- 卡片：缩略图（`/api/gal/img/<cover>?s=t`）+ 一行标题 + 一行 `#作品号`。
  不放来源、时间、点赞数。
- 分页：`has_more` 为真时底部放哨兵，滚到就拉下一页，页大小 24。
- 查看器：整屏浮层，顶部 ✕ 和「3 / 12」，中间可左右换图，底部收藏 / 下载。
  下载走同源 `/api/gal/img/<id>?s=v`（服务端给的是 webp 压缩图，别改后缀）。

## 回退

删掉 `css/gallery.css`、`js/gallery.js` 和 `chat.html` 里两行引用，
`views.js` 的注册口为空时行为与现在完全一致。

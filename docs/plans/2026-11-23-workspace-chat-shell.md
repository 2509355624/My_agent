# 新工作台 · 聊天页壳（P0）

> 日期：2026-11-23　状态：实现中　前置：`2026-11-23-workspace-login.md`

## 1. 为什么做

新界面（`web/workspace/`）第一步是登录页，做完就停在那里没有去处。豆包式的核心是
「打开就是聊天页」，所以第二块补聊天页壳：一句话 → 出图 → 在消息里看结果。

这一期只做**壳和主链**，画廊/漫画/个人页只留可被 push 出来的空壳，内容留给 P1。

## 2. 范围

### 做

| 项 | 说明 |
| --- | --- |
| 聊天页骨架 | 无顶栏、无底栏；只有消息区 + 输入栏（用户 2026-11-23 明确「聊天页不需要顶栏」） |
| 横滑 chip | 输入栏上方一条：`AI 创作` / `画风` / `我的漫画作品`，横向滚动不换行 |
| 输入栏 | 左「＋」（相机 / 相册二选一）、中多行输入、右发送；上限 20000 字 |
| 消息渲染 | 用户 = 蓝气泡右对齐；AI = 卡片左对齐（排队中 / 出图 / 失败三态） |
| 长文折叠 | 用户单条超 1000 字默认折叠，显示前 300 字 + 「展开全部」 |
| 真生图 | 走 `/api/gen/submit`，轮询 `/api/gen/status`，出图用 `/api/gen/img?f=` |
| 消息卡操作 | 复制提示词（`navigator.clipboard`，失败退回选中）、旋转换种子重画（发一条新消息重新排队） |
| 画风抽屉 | 从底部升起，列 `/api/gen/channels` 的中文名，当前默认高亮，选完「设为默认」写 `localStorage` |
| 页面栈 | `push(name)` / `pop()`，右侧滑入、左边缘右滑返回，同步 `history`（浏览器/手机返回键可用） |

### 不做（留给后续期）

- 画廊列表与图片查看器（P1）
- 漫画作品列表与单本页（P2）
- 个人页作品/收藏（P2）
- 反推、做同款（P1）
- 登录校验门禁：本期页面本身不做跳转拦截，挂到 5175 后由服务端发页时拦。

## 3. 模块拆分

```
web/workspace/
  chat.html            聊天页结构（只有 DOM，无内联逻辑）
  css/chat.css         消息、气泡、输入栏、chip
  css/sheet.css        页面栈视图与底部抽屉
  js/api.js            通用 JSON 请求（已存在，补 get）
  js/gen.js            生图接口：渠道 / 提交 / 状态 / 图片地址 / 默认画风
  js/chat.js           消息渲染、输入、折叠、复制、重画、轮询
  js/stack.js          页面栈 push/pop、滑动手势、画风抽屉
  js/views.js          子页壳（顶栏 X + 标题 + 右上用户钮），内容位留空
```

拆法遵守 `docs/development-standard.md`：一个文件一类职责，渲染/请求/栈互不掺。

## 4. 数据流

```
用户输入 → chat.send()
  → gen.submit({skill, prompt, landscape})
  → 立刻插入「排队中」AI 卡片
  → 每 2s 轮询 gen.status()
       ├ 还在队列：卡片显示「前面还有 N 人」
       ├ state=done：卡片换成图 + 复制/重画
       └ state=error：卡片换错误文案 + 重试
```

默认画风 `localStorage["ws_skill"]`，没有就用渠道列表第一个；画风抽屉选中后写回。

## 5. 失败与回退

- 渠道列表拿不到 → 输入框可用但发送时提示「没拿到渠道，去跑图台看看」，不静默失败。
- 提交被拒（队列满 / 提示词空）→ 直接把后端 `error` 原文放进卡片，不改写成自己的话。
- 轮询连续失败 5 次 → 停轮询，卡片标「状态断了，点重试」，不无限打接口。
- 图片 404 → 卡片显示占位块和「图不在了，重画一张」。

## 6. 验收

1. 手机宽度打开 `chat.html`：无顶栏无底栏，只有消息区和输入栏，chip 可横滑；
2. 输入一句 → 发送 → 出现排队卡片 → 变成图，全程不需要刷新；
3. 用户消息超 1000 字自动折叠，可展开；输入超 20000 字被截断；
4. 复制能拿到提示词；重画会新增一条消息并重新排队，旧卡片保持原样；
5. 点三个 chip 各自 push 一个子页，左上 X 与浏览器返回都能退回聊天页；
6. `test_workspace_chat.py` 全绿，原有登录与手机端守卫无回归。

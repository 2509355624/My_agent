## 二、最近这次做了什么

### 1. 游客会话查看（新功能，`175ac58` 起）

管理员只读入口，看游客的扮演记录。

**入口**：QQ 私聊或 @ 机器人发 `#游客会话` → 回一个链接（从 `state/friend_url.txt` 拼）。

**地址**：`https://<tunnel>/guest-view`

**登录**：
- 输 QQ → 查 `state/guest_admins.json` → 不在 = 「无法登录」（统一话术，不给枚举）
- 在 → QQ 私聊发 6 位码（复用 `app/friend_auth.py`：5 分钟、60 秒冷却、连错 5 次锁 10 分钟）
- 验码通过 → `fr_sess` cookie（7 天）

**页面**（`web/guest_view.html`）：
- 桌面：左 300px 列表 + 右详情
- 手机：☰ 抽屉（`min(84vw,330px)`）+ 详情占满
- A− / A+ 调字号（12~22px，存 localStorage）
- 只读：没有删除、没有角色卡管理

**接口**（都在 5175，转发到 5174）：
```
GET  /gv/me       当前登录态
POST /gv/send     发码（先查管理员）
POST /gv/verify   验码
GET  /gv/list     只游客会话
GET  /gv/detail   单条记录
GET  /guest-view?out=1   清 cookie（手机上没法清站点数据）
```

**代码位置**：
- `app/guest_view.py` —— 管理员名单读写（`state/guest_admins.json`）
- `friend_app.py` —— 路由 + 鉴权 + 转发
- `web/guest_view.html` —— 页面

**管理员名单管理**：`http://127.0.0.1:5174/persona_admin` 侧边栏底部，「游客查看 · 管理员」。

## 三、这个页面踩过的坑（重要）

接手的人会重复踩，列在这里：

### 1. 函数内 import 遮蔽外层同名变量

```python
def decide(...):
    if "...":
        from app import qq_api       # ← 这行让 qq_api 变成局部名
    ...
    qq_api.current_session_key()     # ← UnboundLocalError
```

**规则**：函数内 import 一律用别名（`from app import qq_api as _qqapi`）。

### 2. `innerHTML` 替换后还引用被删掉的元素

```js
box.innerHTML = '<div><span id="dTitle"></span></div>';  // 旧 #dTitle 被删
$("dTitle").textContent = ...                            // null → 崩
```

**规则**：替换 innerHTML 后，重新查元素，或者把状态放在不会被替换的节点上（这次改成写 header 的 `#title`）。

### 3. `LIMITS` 里没登记限流桶

```python
if not rate_ok("gv_send"):   # KeyError → 500
```

加了新接口，记得往 `friend_app.LIMITS` 加 `("gv_send": (20, 3600))` 这类条目。

### 4. 浏览器缓存旧页面 / 残留 cookie

`fr_sess` 有效期 7 天，登录过的浏览器会跳过登录框。手机上清不掉 → 用 `?out=1`。

# 整合工作台 UI 方案 v3（定稿）：聊天优先单页（2026-11-23）

> 全部结构问题已拍板。本版推翻 v1/v2 的「底部多 tab」：打开即聊天页，无底栏、无顶栏。
> 本轮只定设计 + demo，**不写页面代码**。

## 0. 已拍板的决策（2026-11-23）

| # | 问题 | 拍板结果 |
| --- | --- | --- |
| 1 | 创作面板从哪进 | 画廊（AI 创作）页底部就是输入框（image#1），点它弹起创作面板（image#2） |
| 2 | 画廊顶端标签 | 文件夹横滑：`全部 / new / showcase / web / 漫画 / 生图页`（image#3）；**不要**展开分类按钮、**不要**站长/公开/我的三段 |
| 3 | 复制提示词范围 | 大大怪生图自带编号，凭编号即可查提示词 → 新图、画廊旧图都能复制 |
| 4 | 横滑 chip 清单 | 只三个：`AI 创作 / 画风 / 我的漫画作品`，不加别的（AI 创作进去就是画廊） |
| 5 | 怎么回聊天页 | 画廊/漫画/个人页左上角 X 返回；手机与浏览器返回键顺着页面栈回退 |

新增确认（同轮口述）：

- 画廊：无搜索、无标题行、去掉点赞只留收藏；卡片只放缩略图 + 名字 + 编号，不放来源/时间/提示词；
- 聊天页：**无顶栏**；用户消息蓝色气泡，AI 消息卡片；输入栏**不要语音**，加号只弹「相机 + 相册」（不收文件）；
- 输入上限 2 万字；用户消息超 1000 字自动折叠；
- 生成消息卡写「前面 N 人排队」，出完显示图片，底部「复制提示词 + 旋转重画」；旋转＝换种子发新消息重新排队；
- 漫画在创作面板里做成「图片生成 / 漫画生成」两个平级入口，不再先图片后切小按钮；剧本**不展示**给用户；
- 画风抽屉：50+ 渠道中文名滚动列表，当前默认高亮，名字后带小三角可展开子类；点名字＝设为默认，只影响默认渠道，仍可「渠道 + 需求」生图；
- 漫画作品列表顶部红字：最多存 30 天、图片可能被清理、作品记录可存 LocalStorage；清浏览器数据才会彻底丢；
- 单本漫画页：底部全部页缩略图条、逐页反馈重画、一键加气泡、下载底图/加气泡图、下载本页/全部；
- 个人页：先不做头像昵称，只留「作品 / 收藏」；登录默认用大大怪验证码（QQ 号 → 下一步 → 验证码 → 登录），登录页走豆包风白色。

## 1. 整体结构

```
打开网页 = 聊天页（默认落地，无底栏、无顶栏）
  ├─ 输入栏上方横滑 chip（入口条）
  │    ├─ AI 创作 → 画廊页（顶端文件夹横滑 + 底部输入框 + 右上用户图标）
  │    │              └─ 底部输入框 → 创作面板〔图片生成 / 漫画生成〕
  │    ├─ 画风 → 滚动抽屉（渠道中文名 → 设为默认）
  │    └─ 我的漫画作品 → 作品列表（红字提醒）→ 单本页
  ├─ 输入栏加号 → 相机 / 相册 → 传图
  └─ 消息流
       ├─ 用户蓝色气泡 / AI 卡片
       ├─ 生图卡：排队 N 人 → 出图 → 复制提示词 / 旋转重画
       ├─ 漫画卡：生成中 → 点跳单本页
       └─ 点图 → 图片查看器：改提示词重画 / 下载
```

画廊页点进单独一张图 → 「做同款」→ 把图发回聊天 → 反推提示词 + 生图（做同款只存在于画廊，不在消息卡里）。

## 2. 聊天页（默认落地）

无顶栏、无底栏。一屏只有消息流 + 底部两件东西：横滑 chip 条、输入栏。

| 区域 | 内容 |
| --- | --- |
| 消息流 | 用户消息＝蓝色气泡；AI 消息＝卡片（生图 / 漫画入口 / 文字） |
| 横滑 chip | `AI 创作`、`画风`、`我的漫画作品`，左右滑动 |
| 输入栏 | 描述框（上限 2 万字，>1000 字自动折叠）+ 加号；**无语音** |
| 加号菜单 | 只两项：拍照（调相机）、相册（选图） |

生图：说话 → 消息卡「前面 N 人排队」→ 出图 → 卡片底部「复制提示词 / 旋转重画」；旋转＝换种子发新消息重新排队。提示词凭编号从后端查，新旧图都能复制。

漫画：说话时选「漫画生成」→ 消息卡「漫画正在生成中」→ 点卡跳单本页；剧本不出现在聊天里。

## 3. 画廊页（点「AI 创作」进入）

豆包式画廊：无搜索、无「画廊」标题行。顶端文件夹横滑 `全部 / new / showcase / web / 漫画 / 生图页`，默认「全部」，左右滑动切换，无展开分类按钮。

| 区域 | 内容 |
| --- | --- |
| 顶端 | 文件夹横滑标签 |
| 主体 | 白色抽屉卡片风格图片网格，可切深色（默认白） |
| 卡片 | 缩略图为主，一行灰字只写名字 + 编号（如「Web · showcase 032」）；不显示提示词、来源、时间、作者、点赞 |
| 底部 | 输入框「描述你想要创作的内容…」→ 点开创作面板 |
| 右上 | 用户图标 → 个人页 |
| 左上 | X → 回聊天页 |

只留收藏，不要点赞。点单独一张图 → 图片查看器 → 「做同款」发回聊天。

## 4. 创作面板（点画廊底部输入框弹起）

字段本地化，image#2 骨架：

| 原豆包字段 | 改成 |
| --- | --- |
| 图片 / 视频 tab | **图片生成 / 漫画生成** 两个平级入口 |
| ＋ 参考图 | 上传参考图＝反推提示词 + 生成（后端现成）；不传＝正常文生图 |
| 使用分身出镜 | **风格**：默认 / moss |
| 模型 4.5 | **画风**：渠道中文名，记住上次用的并默认选中 |
| 比例 自动 | **比例**：只留竖屏、横屏 |
| 描述框 | 描述要创作的内容 |

选「漫画生成」→ 输入漫画需求 → 发表到聊天 → 回消息卡「漫画正在生成中」。

## 5. 图片查看器

黑底全屏（看图器保留黑底，与白色主体无关），顶部 X / 下载，底部输入栏。

| 操作 | 行为 |
| --- | --- |
| 改提示词重画 | 输入「换成汉服」→ AI 改提示词重画 → 回聊天显示新消息卡 → 重新排队 |
| 下载 | 单图直接下载 |
| 做同款（画廊图专属） | 发回聊天 → 反推提示词 + 生图 |

漫画复用查看器：底部换成该本全部页缩略图条，多「一键加气泡」「下载」（问本页 / 全部，按顺序存相册）。

## 6. 画风抽屉

点「画风」chip → 底部升起滚动抽屉：50+ 生图渠道中文名，当前默认高亮，名字后带小三角可展开子类。点名字＝设为默认（只影响默认渠道）；仍可在聊天里用「渠道 + 需求」直接生图。

## 7. 漫画模块

两个入口：创作面板「漫画生成」→ 消息卡 → 单本页；或 chip「我的漫画作品」→ 作品列表 → 单本页。

**作品列表**：顶部红字——「最多为你保存 30 天，图片可能被清理，作品记录可存本地；记得及时下载到手机。」每张卡片显示第一页缩略图。

**单本页**：全屏看当前页 + 底部全部页缩略图条；说不满意的地方 → AI 重新构建该页；重画按钮重画当前页；下载按钮问「本页 / 全部」按顺序存相册；一键加气泡 → 得到底图与加气泡图两种。

## 8. 个人页与登录

- 个人页：先不做头像昵称，只有「作品 / 收藏」两个 tab，去掉点赞。
- 登录页（豆包风白色，要好看）：输入 QQ 号 → 下一步 → 获取验证码 → 输入验证码 → 登录。默认走大大怪验证码登录。

## 9. 主题与视觉

- 默认白色抽屉卡片风格（浅灰底 + 白卡 + 轻阴影），可切深色；
- 沿用画廊已有 `data-theme` 语义色变量，刷新无闪色；
- 圆角 12–16，8pt 间距网格，触控目标 ≥44px；
- 字体只用 400/500 两档，少字，一屏一个主操作；
- 超长文本处理：输入框 2 万字上限，消息 >1000 字折叠。

## 10. 后端能力核对

| 需求 | 后端现状 |
| --- | --- |
| 参考图反推 + 生图 | 现成：跑图台 `_recall_tags`，上传图先反推英文提示词再文生图 |
| 排队人数 | 现成：`image_jobs` / `comfy.lock` 队列可查 |
| 复制提示词 | 现成：凭生图编号查提示词，新旧图皆可 |
| 收藏 | 现成：画廊收藏接口 |
| 漫画逐页重画 / 加气泡 / 下载 | 现成：漫画接口可复用，批量存相册需前端做 |
| 登录（QQ 号 + 验证码） | 现成：大大怪验证码登录后端 |
| 渠道中文名 / 默认渠道 | 需把渠道配置映射中文名，默认渠道存本地 |
| LocalStorage 存漫画作品记录 | 新增：前端存任务元数据，图片仍依赖后端文件 |

## 11. 明确不做

管理页、状态页、小说、showcase 管理、社区化、搜索、文件（非图片）上传、语音输入、点赞。

## 12. 分期与验收

| 期 | 内容 | 验收点 |
| --- | --- | --- |
| P0 壳 + 聊天页 | 横滑 chip、输入栏、页面栈、主题、2 字字上限与折叠 | 打开即聊天、无顶/底栏；三个 chip 可达；深色切换保持 |
| P1 画廊 + 创作面板 | 文件夹横滑、创作面板、做同款、查看器 | 画廊无搜索无标题；输入框弹面板；做同款回聊天 |

每期独立可回退，旧五条路由与全部 API 不动。

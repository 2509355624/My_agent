# 整合工作台 UI 方案 v3：聊天优先单页（2026-11-23）

> 这一版推翻 v1/v2 的「底部多 tab」结构。用户确认：打开网页就是豆包那样的聊天页，**没有底部状态栏**。画廊、漫画、个人全部从聊天页里的入口进入。

## 0. 这一版推翻了什么

| v2（已废弃） | v3（本版） |
| --- | --- |
| 底部五格：工作台/画廊/创作/漫画/角色 | **无底栏**，打开即聊天页 |
| 创作是中间凸起按钮 | 输入栏上方横滑 chip 是入口条 |
| 画廊是独立 tab | AI 创作 → 进去就是画廊 |
| 工作台看进度 | 排队信息写在生图消息卡里 |
| 漫画独占 tab | 「我的漫画作品」在横滑 chip 里，单本页独立 |

## 1. 整体结构

```
打开网页
  └─ 聊天页（默认落地，无底栏）
       ├─ 输入栏上方横滑 chip
       │    ├─ AI 创作 → 画廊页（顶端文件夹横滑 + 右上用户图标）
       │    ├─ 画风 → 滚动抽屉（渠道中文名 → 设为默认）
       │    ├─ 我的漫画作品 → 作品列表 → 单本页
       │    └─ （其余 chip 按需要加）
       └─ 消息里的图片 → 图片查看器
            ├─ 提问编辑 → AI 改提示词重画
            └─ 做同款 → 把图发回聊天 → 反推提示词 + 生图
```

## 2. 聊天页（默认落地）

照 image#2 / #3 / #9 的豆包对话界面，白底、少字、消息气泡。

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 左：菜单/返回；中：产品名 + 下拉；右：用户图标（进个人页） |
| 消息流 | 用户消息＝蓝色气泡；AI 消息＝卡片（图 / 生成中 / 漫画入口） |
| 输入栏上方 | **左右滑动的 chip 条**，放「AI 创作 / 画风 / 我的漫画作品」等，显眼位置 |
| 输入栏 | 描述框 + 语音图标 + 加号（上传参考图） |

生图交互：
- 说话 → 回一张**消息卡**，写明「前面 N 人排队」；
- 生成中显示进度（image#10 那种骨架 + 百分比）；
- 完成后正常显示图片；
- 卡片底部：**复制提示词**按钮、**旋转重画**按钮（换种子＝发一条新消息重新排队）。

漫画交互：说话选漫画模式 → 回消息卡「漫画正在生成中」→ 点卡片跳漫画页；生成完毕后同一张卡可再次跳转。

## 3. 画廊页（点「AI 创作」进入）

照 image#4：顶端是**文件夹横滑标签**（全部 / new / showcase / web / 漫画 / 生图页），点击展开分类按钮可看到全部分类——这是站长按文件夹上传的结构。

| 区域 | 内容 |
| --- | --- |
| 顶端中间 | 文件夹横滑标签 + 展开分类按钮 |
| 右上角 | 用户图标 → 个人页（作品 / 收藏） |
| 主体 | 白色抽屉卡片风格的图片网格，可切深色模式 |
| 卡片 | 缩略图为主，一行灰字带来源/时间；**不显示提示词、作者、使用量、点赞** |

去掉的：搜索按钮、"画廊"标题行、三段切换（站长/公开/我的）、点赞。收藏保留，放在图片查看器或个人页。

## 4. 创作面板（画廊页里触发）

照 image#7，从底部升起，字段全部本地化：

| 原豆包字段 | 改成 |
| --- | --- |
| 图片 / 视频 tab | 图片 / 漫画 |
| ＋ 参考图 | 上传参考图＝**反推提示词 + 生成**（后端现成）；不传＝正常文生图 |
| 使用分身出镜 | **风格**：默认 / moss |
| 模型 4.5 | **画风**：渠道中文名，记住上次用的并默认勾选 |
| 比例 自动 | **比例**：只留竖屏、横屏两个 |
| 描述框 | 描述要创作的内容 |

选「漫画」+ 风格（默认/moss）→ 输入漫画需求 → 开始创作。

## 5. 图片查看器

照 image#11 / #13 / #15：黑底全屏，顶部 X / 下载 / 分享，底部图片缩略图条 + 输入栏。

| 操作 | 行为 |
| --- | --- |
| 提问编辑 | 输入「换成汉服」→ AI 改提示词重画 → 回聊天页显示新消息卡（image#12） |
| 做同款 | 把这张图发回聊天 → 大大怪反推提示词 + 生图 → 新消息卡 |
| 复制提示词 | 新生成的图可复制；画廊里的旧图未必有提示词（见待确认） |
| 下载 | 单图直接下载 |

漫画页复用同一套查看器，但底部换成**该本漫画全部页面的缩略图条**，并多一个下载按钮（问下载本页 / 全部，按顺序存相册）。

## 6. 画风抽屉

点「画风」chip → 从底部升起滚动抽屉，列**生图渠道的中文名**（如「三档 / anima线条 / …」），当前默认高亮，选中后点「设为默认」。只是设置默认渠道，不影响「渠道 + 需求」的生图方式——你依旧可以像在 QQ 里那样直接说渠道名。

## 7. 漫画模块

两个入口：

- **生成**：创作面板选「漫画」→ 聊天消息卡 → 跳单本页；
- **回看**：输入栏上方 chip「我的漫画作品」→ 作品列表 → 单本页。

**作品列表**（照 image#14）：
- 顶部红字：「不会为你长期保存，记得自己保存到手机，防止清理后找不到」；
- 每张卡片显示第一页缩略图，点击进单本页。

**单本页**：
- 全屏看当前页，底部全部页缩略图条；
- 输入栏说不满意的地方 → AI 重新构建该页；
- 重画按钮 → 重画当前页；
- 下载按钮 → 问「本页 / 全部」→ 按顺序存相册。

## 8. 个人页（右上角用户图标进入）

照 image#5：头像 + 昵称，下面两个 tab：**作品 / 收藏**。点赞去掉，只留收藏。

## 9. 主题与视觉

- 白色为默认（抽屉卡片风格：浅灰底 + 白卡 + 轻阴影），可切深色模式；
- 沿用画廊已有的 `data-theme` 语义色变量，刷新无闪色；
- 圆角 12–16，8pt 间距网格，触控目标 ≥44px；
- 字体只用 400/500 两档，少字，一屏一个主操作。

## 10. 后端能力核对

| 需求 | 后端现状 |
| --- | --- |
| 参考图反推 + 生图 | **现成**：跑图台 `_recall_tags`，上传图先反推英文提示词再文生图 |
| 排队人数 | 现成的 `image_jobs` / `comfy.lock` 队列可查 |
| 复制提示词 | 新生成的图可从任务记录取；画廊里的旧图未必有 |
| 收藏 | 画廊已有收藏接口 |
| 漫画逐页重画 / 下载 | 现有漫画接口可复用，下载需前端批量存相册 |
| 渠道中文名 / 默认渠道 | 需把渠道配置映射成中文名，默认渠道存本地 |

## 11. 需要你拍板的点

1. **AI 创作 = 画廊，那创作面板从哪进？** 我的理解：点「AI 创作」进画廊页，画廊页底部或某个 chip 再弹创作面板（image#7 那种）。如果这个理解错，你说一下创作面板的入口。
2. **画廊顶端的标签到底是哪一组？** 你说「本机改站长」，又给了一张「全部/new/showcase/web/漫画/生图页」的文件夹图。是「站长/公开/我的」三段，还是「全部/new/…」文件夹，还是两者叠加（先选来源再选文件夹）？
3. **复制提示词的范围**：新图能复制；画廊里的旧图你也要能复制吗？如果要，得先确认旧图任务记录里有没有存提示词。
4. **横滑 chip 的最终清单**：现在有「AI 创作 / 画风 / 我的漫画作品」，还要不要放别的（比如「画廊」单独一个）？
5. **没有底栏后，怎么回到聊天页？** 画廊页/漫画页/个人页左上角都放返回箭头，是否够用？

人设

写进 system prompt 的 Role 段，决定这个 agent 怎么说话。保存后下一轮对话即生效，不用重启。

模型

留空即继承 .env 的全局默认。给单个 agent 指定，比如让带图对话的 agent 用 DeepSeek、其余走火山。

上下文预算

单次请求最多携带多少 prompt token，超过就压缩旧历史。管的是「每轮愿意花多少钱」， 不是模型的物理上限——模型能装几十万，不代表你愿意每轮都付这个钱。留空即继承全局。

会话管理

每个群、每个私聊各有一条独立的会话线，互不影响。删掉某一条 = 重置那条对话， 这个 agent 的人设、工具与技能白名单都不动。删除不可恢复。 会话列表已挪到右侧那一列（可搜 QQ 号 / 群名，点行展开该会话的开关）。
全部
一键关闭 / 恢复这个 agent 在所有 QQ 会话的生图（网页端不受影响）。 单独某个群不想让它画，用群行里的「生图」开关。
NAI（群主独立的 NovelAI 账号）全局总闸：开 = 允许给白名单里的群用； 关 = 全部群都不走 NAI。单独的群要「开 NAI」仍用群行里的「NAI」开关，且全局必须开着才生效。 群主的要求是只给特定群用，所以默认全关、按需加白名单。
QQ 里发出去的图用 JPG（省流量）还是 PNG（无损）。 PNG 单张约 1.4~2.2 MB，比 JPG（约 0.18 MB）大十倍，群里发得慢也更占相册。 只影响发出去那一张，ComfyUI output 里的原图永远不动。 某个群想单独用别的格式，用群行里的「格式」开关。
发图前的 NSFW 闸门，群聊和私聊各一个总开关（默认都关）： 开 = 那一类会话的生图发出去之前先让识图模型判一次，命中 大面积皮肤裸露 / 性暗示 / 暧昧动作任一就不发并回一句提示，拿不准也拦。 识图超时 / 报错一律拦下不发（fail-closed），所以识图服务一抖所有图都会发不出去。 单个群 / 单个私聊想跟总开关不一样，用行里的「审核」开关覆盖。 「审核提示词」按钮可以自己改判定口径。
整份替换内置的审核提示词。必须保留最后那句「只输出一行 JSON」 （字段 allow / reason / category，category 只能是 ok|skin|sexual|nudity|other） ——丢了它模型回的话解析不出来，会被当成审核失败，所有图都发不出去。 留空保存 = 恢复内置默认。
对方发图给机器人时，把图读成文字用的那份要求 （对话模型没有视觉能力，靠识图模型当它的眼睛）。内置默认是 「描述画面 + 原样提取文字，不翻译」——觉得它读得不细、抓不到重点， 可以在这里整份换成自己的写法，热生效、不用重启。 文本里放 {question} 的位置会被替换成对方这轮的原话；没放则自动补在 末尾一行，所以「带上问题」这件事丢不掉。 只管这一条链路：生图发出去前的 NSFW 审核（上面那个「审核提示词」）、 表情包打标签各有各的提示词，都不吃这个开关。
整份替换内置的识图提示词。输出是一段给另一个模型看的纯文本， 没有必须遵守的格式，写宽写窄只影响它读得细不细。 建议保留「原样提取图中的文字，不要翻译、不要改写」这句—— 少了它，报错截图里的英文会被翻成中文，后面就没法拿原文去搜错误码。 留空保存 = 恢复内置默认。
私聊
私聊总开关：关掉 = 任何人的私聊都不再回复（白名单也不看），群聊不受影响。热生效。
白名单开关关掉 = 名单不生效， 任何人的私聊都能聊（黑名单和上面的私聊总开关照常拦）。 开着时：名单外的 QQ（包括陌生人临时会话）一律静默不回、不出图， 清空名单 = 谁都私聊不了。点号码可移除。热生效，不用重启。
张 0 = 不限量。只算私聊，群聊一张都不占。
名单里的 QQ 私聊生图不限量； 其余人每天最多上面那个张数。跑失败的那张会退还，跨天自动归零（按本机日期）。 额度是「接单就扣」，所以连点刷队列也拦得住。 这里管的是「谁生图不限量」，跟上面的私聊白名单（管「谁能私聊」）是两回事， 刻意没合并。热生效，不用重启。
群聊
秒 没被 @ 时最多每这么多秒主动接一次话，0 = 不限频。 想让某个群单独不同，点群行里的「频率」按钮。
% 收到一批消息后去问一次模型的概率，默认 12（≈1/8）。 0 = 从不主动开口，100 = 每批都问。单群可单独设，见群行的「概率」。
秒 两次「要不要接话」的判断之间至少隔这么久——判断也是一次调用。 0 = 不做这道闸（那就只剩概率门挡着）。

今日用量

按「会话 / 隐形调用」聚合的 token 消耗。命中率 = 命中 ÷（命中+未命中）， 命中越高中间越便宜。vision=识图、interject=接话判断、longterm=长期记忆摘要、 compact=上下文压缩摘要，这些是 LLM 后台里「对不上号的请求」的出处。
